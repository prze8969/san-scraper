# CODEMAP.md: Source Code Architecture & File Reference

| File Path | Purpose | Key Classes & Functions | Reads & Returns | Imported By | Limits & Enforced Bounds |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `src/cli.py` | CLI entry point for processing single files or directories. | `main()`, `run_salvage(path, output_dir, verbose, quiet) -> int` | Reads CLI args (`sys.argv`), invokes engine, returns exit code (`0` or `1`). | Executed directly (`python -m src.cli`, `salvage.bat`, `salvage`). | Directory recursion bounds; checks path existence. |
| `src/reader.py` | Memory-safe binary slice reader. | `BoundedBinaryReader`, `BoundsError`, `TruncationError` | Reads raw `bytes`; provides `read_bytes()`, `seek()`, `unpack()`, `unpack_at()`, `peek_bytes()`. | All parsers, `SalvageEngine`. | `max_alloc=32MB`; bounds checking against EOF; negative length prevention. |
| `src/models.py` | Core data dataclasses and JSON serialization. | `RecordStatus`, `DamageType`, `DamageBlock`, `RecoveredRecord`, `FileRecoveryResult` | Converts internal records to JSON dicts via `.to_dict()`. | All parsers, `engine.py`, `reporter.py`, tests. | `_sanitize` recursively encodes raw `bytes` to UTF-8/Latin-1 strings. |
| `src/detector.py` | Magic signature dictionary & header tester. | `FormatDetector`, `detect(reader) -> str` | Reads first 16 bytes from `BoundedBinaryReader`; returns format string. | `engine.py`, `detector_pipeline.py`. | Fixed 16-byte peek. |
| `src/detector_pipeline.py` | Multi-tier format detection pipeline. | `DetectionCandidate`, `PipelineDetector.detect_candidates(data, analysis, filename) -> list[DetectionCandidate]` | Evaluates magic, whole-buffer signature, and file extension; returns ranked list. | `engine.py`. | Limits candidates to high-confidence matches. |
| `src/engine.py` | Central recovery orchestrator. | `SalvageEngine.process_file(path) -> FileRecoveryResult`, `process_bytes(name, data) -> FileRecoveryResult` | Reads file bytes from disk; orchestrates parser, carver, probes, coverage. | `cli.py`, tests, demo scripts. | Path sanitization on output directory; bounded file reading. |
| `src/reporter.py` | Report writer and terminal visualizer. | `Reporter.write_file_result(res)`, `write_batch_summary(results)`, `print_file_terminal_report(res)` | Takes `FileRecoveryResult`; writes `.json` files and prints ANSI/ASCII terminal report. | `cli.py`. | Path containment verification via `relative_to` on output paths. |
| `src/analysis/file_analyzer.py` | Generic statistical and signature analyzer. | `FileAnalyzer.analyze() -> dict` | Computes SHA-256, Shannon entropy, byte frequency, printable strings, stride autocorrelation. | `engine.py`. | Max 100 printable strings; max 50 detected signatures; sample size caps. |
| `src/recovery/carver.py` | Bounded file carver & coverage calculator. | `Carver.carve_all()`, `GenericRecovery.recover_heuristic_records()`, `calculate_coverage()` | Carves embedded PNG, ZIP, JPEG from byte offsets; computes disjoint byte coverage. | `engine.py`. | 16 MB maximum carving slice per object; max 100 heuristic records. |
| `src/recovery/extractor.py` | Container file extractor for archives. | `extract_container_files(result, raw_data, output_dir)` | Writes recovered records to `<output_dir>/<name>.extracted/`. | `engine.py`. | Path containment verification (`relative_to`); directory traversal prevention. |
| `src/probes/probe_runner.py` | 400+ forensic probe battery. | `ProbeResult`, `ProbeRunner.run_all_probes() -> list[ProbeResult]` | Runs parameterized probe checks across offsets and byte families. | `engine.py`. | Scan bounds (offsets 0..64 and trailing 64 bytes); memory-bounded slices. |
| `src/probes/probe_documenter.py` | Forensic probe documenter & layout mapper. | `ProbeDocumenter.document_probes()`, `_infer_layout()` | Writes `.probes.txt` and `.probes.json`; computes layout map regions. | `engine.py`. | Output directory path containment. |
| `src/formats/base.py` | Abstract base class for format parsers. | `BaseParser.parse(filename, reader) -> FileRecoveryResult` | Interface contract for all format parsers. | All parsers in `src/formats/`. | Inherited abstract contract. |
| `src/formats/wks.py` | Lotus 1-2-3 Release 1A parser. | `WksParser` | Parses sequential records; builds cell `grid` in `metadata`. | `engine.py`. | Record length cap 64 KB; max 50,000 records. |
| `src/formats/pak.py` | Quake PAK archive parser. | `PakParser` | Parses 12B header & 64B directory entries; recovers intact files. | `engine.py`. | Path sanitization; entry offset and size bound checks; max 10,000 files. |
| `src/formats/wad.py` | Doom IWAD/PWAD archive parser. | `WadParser` | Parses 12B header & 16B lump entries; handles zero-size markers. | `engine.py`. | Max 50,000 lumps; lump boundary bounds checking against file size. |
| `src/formats/zip.py` | Standard ZIP archive parser. | `ZipParser` | Scans local headers (`PK\x03\x04`), parses Central Directory with fallback. | `engine.py`. | 16 MB decompression cap per entry; path traversal sanitization; max 10,000 entries. |
| `src/formats/gzip.py` | RFC 1952 GZIP stream parser. | `GzipParser` | Decodes header flags, decompresses deflate stream, verifies CRC-32/ISIZE. | `engine.py`. | 16 MB decompression cap. |
| `src/formats/png.py` | ISO/IEC 15948 PNG image chunk parser. | `PngParser` | Parses 8B signature and chunk framing; checks per-chunk CRC-32. | `engine.py`. | Max 10,000 chunks; max chunk length 32 MB. |
| `src/formats/libra98.py` | LIBRA-98 provisional validation parser. | `Libra98Parser` | Parses 32B header and 48B records; validates checksums. | `engine.py`. | Max 10,000 records; bounds check against file size. |
| `src/formats/lablog.py` | LABLOG provisional telemetry parser. | `LablogParser` | Parses 24B header and variable length blocks; validates block CRC32. | `engine.py`. | Max 10,000 blocks; max block size 64 KB. |
| `src/formats/vault.py` | VAULT provisional archive parser. | `VaultParser` | Parses 32B header and index entries; handles PackBits RLE & XOR. | `engine.py`. | 16 MB decompression cap per entry; max 10,000 entries. |
| `src/formats/unknown.py` | Fallback parser for unrecognized formats. | `UnknownParser` | Returns base recovery result with invalid header and zero records. | `engine.py`. | Zero allocation. |
