# FORMATS.md: Supported Binary Formats & Specifications

| Format | Status | Magic Signature | Header / Record Layout | Parser Path | Test Path | Known Limitations | Specification Source |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Lotus 1-2-3 (.WKS)** | Implemented from documented layout | None (Starts with BOF opcode `0x0000`, len `2`, ver `0x0404`) | Stream of records: 2B opcode, 2B length, N-byte payload. Cell types: BLANK (`0x000C`), INTEGER (`0x000D`), NUMBER (`0x000E`), LABEL (`0x000F`), FORMULA (`0x0010`). EOF (`0x0001`). | `src/formats/wks.py` | `tests/test_wks.py` | Formulas are kept inert without dynamic evaluation; some 80-bit non-IEEE float variants logged in hex. | `WSFF1.TXT`, `WSFF2.TXT`, Gnumeric `lotus.c`, LibreOffice Calc filter. |
| **Quake PAK (.PAK)** | Implemented from documented layout | `PACK` (`50 41 43 4B`) | 12B Header: magic (4B), directory offset (4B uint32 LE), directory size (4B uint32 LE). Directory: 64B entries (56B null-padded path, 4B offset, 4B size). | `src/formats/pak.py` | `tests/test_pak.py` | Truncated directory entries beyond EOF isolated as damage blocks. | id Software Quake archive specification (`quakedef.h`). |
| **Doom WAD (.WAD)** | Implemented from documented layout | `IWAD` / `PWAD` | 12B Header: magic (4B), numlumps (4B uint32 LE), directory offset (4B uint32 LE). Directory: 16B entries (4B offset, 4B size, 8B ASCII name). | `src/formats/wad.py` | `tests/test_known_formats.py` | Zero-length section marker lumps (`F_START`, `S_END`) are valid and have size 0. | id Software Doom source release (`w_wad.c`, `doomdef.h`). |
| **ZIP (.ZIP)** | Implemented from documented layout | `PK\x03\x04` (Local header) / `PK\x01\x02` (Central dir) | Local header (30B + name + extra) + payload. Central directory at file end with EOCD (`PK\x05\x06`). Recovers directly from local headers if central dir is missing. | `src/formats/zip.py` | `tests/test_known_formats.py` | Supports Stored (0) and Deflate (8). Enforces 16 MB max uncompressed size per file to prevent decompression bombs. | PKWARE APPNOTE.TXT (Section 4.3). |
| **GZIP (.GZ)** | Implemented from documented layout | `\x1f\x8b` (`1F 8B`) | 10B Header: ID1, ID2, CM (8=deflate), FLG, MTIME (4B), XFL, OS. Optional FEXTRA, FNAME, FCOMMENT, FHCRC. Trailing 8B: CRC32, ISIZE. | `src/formats/gzip.py` | `tests/test_known_formats.py` | Multi-stream concatenated GZIP treated as single primary stream. | IETF RFC 1952. |
| **PNG (.PNG)** | Implemented from documented layout | `\x89PNG\r\n\x1a\n` (`89 50 4E 47 0D 0A 1A 0A`) | 8B Signature followed by chunk framing: 4B length (BE), 4B chunk type (ASCII), N-byte data, 4B CRC-32 (over type + data). Ends with IEND chunk. | `src/formats/png.py` | `tests/test_known_formats.py` | Does not assemble scanline filters or decode image pixels; verifies chunk framing and CRC-32. | ISO/IEC 15948:2004 / W3C PNG Specification. |
| **LIBRA-98 (.LIB)** | Provisional | `LIBRA98\x00` (`4C 49 42 52 41 39 38 00`) | 32B Header: magic (8B), ver (2B), flags (2B), header size (4B), count (4B), rec size (4B), crc32 (4B). 48B Records: ID (4B), timestamp (4B), status (2B), val (4B), label (30B), crc16 (2B). | `src/formats/libra98.py` | `tests/test_libra98.py` | Layout is provisional; no official external samples available in workspace. | Provisional test contract (see FIELD-LOG.md). |
| **LABLOG (.LAB)** | Provisional | `LABLOG01` (`4C 41 42 4C 4F 47 30 31`) | 24B Header: magic (8B), ver (2B), session (4B), block count (4B), reserved (6B). Variable length blocks: block ID (4B), type (2B), flags (2B), timestamp (4B), length (4B), payload, crc32 (4B). | `src/formats/lablog.py` | `tests/test_lablog.py` | Layout is provisional; block framing is verified defensively. | Provisional test contract (see FIELD-LOG.md). |
| **VAULT (.VLT)** | Provisional | `VAULT\x01\x00\x00` (`56 41 55 4C 54 01 00 00`) | 32B Header: magic (8B), ver (2B), entry count (4B), index offset (4B), flags (2B), reserved (12B). 48B Index: ID (4B), offset (4B), comp size (4B), uncomp size (4B), flags (2B), XOR key (1B), name (27B). | `src/formats/vault.py` | `tests/test_vault.py` | PackBits RLE capped at 16 MB decompression per entry; XOR key 1-byte mask. Layout provisional. | Provisional test contract (see FIELD-LOG.md). |
| **UNKNOWN / EMPTY** | Fallback handler | None | Catch-all handler. Emits 0 verified records and invalid header; triggers heuristic string and stride analysis. | `src/formats/unknown.py` | `tests/test_analysis_and_recovery.py` | No format claim; reports verified coverage as 0%. | Fallback recovery design. |
